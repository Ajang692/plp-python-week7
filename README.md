# PLP Python Week 7 Assignment

## Assignment: File Handling and CSV Report Builder

### Project Files

1. **my_notes.py** – Writes, appends, reads and counts notes using Python file handling.
2. **my_notes.txt** – Stores the four notes generated by the notes program.
3. **report_builder.py** – Reads learner data from a CSV file and generates a report.
4. **hubs.csv** – Contains learner names, hubs and scores.
5. **report.txt** – Contains the generated learner performance report.

### What happens if "a" is changed to "w"?

Changing `"a"` to `"w"` would overwrite the existing contents of the file instead of adding a new note. This means the first three notes would be erased and only the fourth note would remain.
